# Program_pet

Коллекция полезных десктопных приложений и браузерных расширений для повседневных задач.

---

## Проекты

### [Соотношение сторон: Калькулятор](aspect_ratio/)

Калькулятор для расчёта пропорций изображения с поддержкой популярных форматов.

**Возможности:**
- Поддержка форматов: `1:1`, `4:3`, `5:4`, `16:9`, `16:10`, `21:9`
- Автоматический пересчёт ширины и высоты
- Выбор единиц измерения (пиксели и другие)
- Валидация ввода (только цифры)

**Технологии:** Python, Tkinter

**Запуск:**
```bash
cd aspect_ratio
python aspect_ratio.py
```

### [Lost URL](block-url-extension/)

Браузерное расширение для Chrome, которое перенаправляет на другую страницу при обнаружении определённых ключевых слов в URL.

**Возможности:**
- Блокировка нежелательных сайтов по ключевым словам
- Настройка списка блокируемых URL через popup
- Гибкие настройки через страницу опций
- Работает в фоновом режиме

**Технологии:** JavaScript, Chrome Extension API (Manifest V3)

**Установка:**
1. Откройте `chrome://extensions/`
2. Включите **Режим разработчика** (правый верхний угол)
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку `block-url-extension`

### [Таймер обратного отсчёта](countdown-timer/)

Красивый и функциональный таймер с визуальной анимацией и звуковыми сигналами.

**Возможности:**
- Установка времени (часы, минуты, секунды)
- Круговая анимация прогресса
- Звуковые сигналы через заданные интервалы
- Визуальная индикация окончания (мигание окна)
- Приятные мелодичные звуки (winsound)
- Современный тёмный интерфейс

**Технологии:** Python, Tkinter, Pygame, Threading

**Запуск:**
```bash
cd countdown-timer
pip install -r requirements.txt
python contdown_timer.py
```

**Сборка исполняемого файла:**
```bash
python setup.py
```
